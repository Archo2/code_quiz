# Code Quiz

A timed, multiple-choice JavaScript quiz with a high-score board.

**Live demo:** https://archils.github.io/code_quiz/

## Features

- Countdown timer starts when you begin the quiz
- Each wrong answer takes 10 seconds off the clock
- Quiz ends when all questions are answered or time runs out
- Save your initials and score; high scores are kept in `localStorage`

## Built With

HTML · CSS · JavaScript (Web APIs: DOM, timers, localStorage)

## How to Use

1. Open the [live demo](https://archils.github.io/code_quiz/) or open `index.html` in your browser.
2. Click **Start Quiz** and answer each question before time runs out.
3. Enter your initials to save your score.
